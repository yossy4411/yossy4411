## プロジェクト
僕が今進めているプロジェクトをいくつか紹介しましょうかね。

### 学習中
まあ、プロジェクトを進めるにあたって、学習することは非常に重要になる礎でありますから、学習から進める訳なんですよ。結局、この段階がバカみたいに長引いてプロジェクトの実装になかなか着手できないことが多々あるわけなんですけど。それはさておき、以下に僕が今学習中のジャンルを書いておきましょう。

- Kubernetesのキホン
- AIの仕組み、作り方
- 地震について（発振機構、地震動の周期など）

### 進行中
今進んでいるプロジェクトです、必死に実装していますが途中でめんどくなることがあって、そうなった場合は僕のGitHubから消えてると思います。  
てかそもそもプライベートリポジトリとして作成してリリース段階になったらパブリックになるので、そこまで影響は出ないと思いますけどね。

- **OGSP (おかゆグループ地震計プロジェクト)**  
  オープンソースな災害対策ネットワークを構築する試み。ソフトウェア開発のほか、地震計の設計に関するスキルも必要となってきている。
- Soraori (一時的に開発停止中)  
  オープンソースフルスタック動画編集ソフト。僕のYouTubeチャンネルでの動画投稿向けに開発を予定しているが、受験のために一時的に開発への着手を見送っている。
